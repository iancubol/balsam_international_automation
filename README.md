# Project description
This automation framework uses Playwright and Typescript and is intended to answer the assessment instructions for Balsam International

# Framework setup and dependencies
To setup, you will need:
- NodeJS
- Visual Studio Code editor

Once requirements are ready,
1. Install the Playwright VSCode Extension
  - Open VSCode.
  - Go to the Extensions panel (or press Ctrl+Shift+X).
  - Search for "Playwright Test for VSCode" (by Microsoft).
  - Click Install.


# Instructions to clone and execute the tests
- If you have GITHUB desktop installed, use the link on this github repo to clone this project
- If none, using the link of this repo,
  1. Open a command prompt
  2. Navigate to the folder where you want the repo:
  3. Copy the repository URL from GitHub:
    - Go to the repo page on GitHub.
    - Click the green Code button.
    - Choose HTTPS or SSH, then copy the URL.
  4. Run the git clone command:
    such as: git clone git@github.com:username/repository.git
  5. Navigate into the cloned repo:
    cd repository

To execute the test:
Option 1: Run Tests from the Testing Sidebar
  - Click the beaker icon in the Activity Bar to open the Testing sidebar.
  - You’ll see a list of your tests.
  - Click the green triangle ▶️ next to a test to run it.
  - To run all tests, click the white triangle at the top of the list.

Option 2: Run Tests from the Terminal
  - npx playwright test

Option 3: Run in Headed Mode (with Browser UI)
  - npx playwright test --headed

# Expected test outputs
After each execution, you can check the index.html generated by:
  - npx playwright show-report

You can also look at:
- playwright-report
- test-results

These shows artifacts such as screenshots and video recording of test execution
